# Machine Learning for Probabilistic Short-Term Electricity Demand Forecasting in Great Britain

Personal research project forecasting GB electricity demand (point + probabilistic), evaluating
against naive baselines, extreme-event conditions, and a back-of-envelope estimate of real-world
impact.
